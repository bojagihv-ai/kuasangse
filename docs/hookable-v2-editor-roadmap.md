# Hookable ver2 Editor Roadmap

이 문서는 Hookable 참조 화면에서 아직 우리 프로그램에 완전히 구현되지 않은 편집기 기능을 놓치지 않기 위한 체크리스트다.

## 현재 완료된 범위

- Hookable ver2 기획 초안 보드
- 기존 15섹션 유지 + Hookable ver2 생성 사고방식 선택
- 섹션별 초안 카드 15개
- DB/온톨로지/분석 근거 자연어 표시
- Hookable 섹션 타입 라이브러리 21종
- 분석 없이 섹션 설정 진입
- 섹션 설정 화면에서 바로 섹션 생성용 이미지 업로드
- 미리보기 화면 Hookable식 좌측 편집 도구 패널 1차
- 좌측 패널 탭: 페이지, 텍스트, 폰트, 사진, AI 생성, 도형, 레이어, 색상
- 현재 편집 섹션 선택
- 텍스트 템플릿을 현재 섹션 콘텐츠에 즉시 반영
- 폰트 프리셋을 현재 섹션에 즉시 반영
- 사진 탭에서 기존 이미지 삽입/교체 모달 연결
- AI 생성 탭에서 현재 섹션 재생성/이미지컷 탭 이동 연결
- 도형 탭에서 배지/구분선/스펙 표/말풍선 의도를 섹션 포인트와 레이아웃 지시에 반영
- 레이어 탭에서 기존 레이어 모드/슬라이더/미리보기 선택과 연결
- 색상 탭에서 섹션 또는 전체 섹션 컬러 프리셋 적용
- 쉬운 용어 중심으로 패널 문구 정리: 글, 글꼴, 스티커, 위치
- 자유 글상자를 현재 섹션 위에 별도 이동 요소로 삽입
- 스티커/말풍선/정보 박스/구분선/동그라미/스펙표를 현재 섹션 위에 별도 이동 요소로 삽입
- 추가한 글상자/스티커를 위치 탭에서 선택, 숨기기, 삭제
- 추가한 글상자/스티커를 미리보기에서 드래그 이동 및 조정창으로 세부 조정
- 페이지 탭에서 섹션 썸네일 표시
- 위치 탭에서 기본/추가 요소 숨김, 잠금, 앞뒤 순서 조정
- AI 생성 탭에서 직접 프롬프트 입력 후 현재 섹션 재생성
- 위치 탭에서 선택한 레이어 이름 변경
- 페이지 탭에서 선택 섹션 위/아래 순서 이동
- 사진 탭에서 대표 이미지/섹션 이미지/이미지컷/추가 이미지를 자산 목록으로 표시하고 바로 적용
- 페이지 탭에서 섹션 내용 복사/붙여넣기와 섹션 비우기 지원
- 사진 탭에서 현재 섹션 배경색 빠른 설정 지원
- 페이지 탭에서 섹션을 삭제하지 않고 미리보기/내보내기에서 숨김 처리
- 레이어 탭에서 선택한 제목/본문/CTA/포인트/추가 글상자의 실제 문구 수정
- 사진 탭에서 자산 검색, 이름 변경, 현재 섹션 사용 표시
- AI 부분수정 모달에 선택 영역 보호 규칙, 빠른 요청, 수정 기록/전후비교 진입점 추가
- Hookable ver2 보드에서 세부 입력/자연어 입력 모드 선택 지원
- 자연어 특징 목록을 초안/근거 로그/이미지 생성 지시에 반영
- 섹션 초안 카드에 섹션 역할별 아이콘 표시
- Hookable ver2 보드에서 생성 방식을 AI만/혼합/원래대로 3택으로 선택
- Gemini 연결 정보에 키 마스킹, Backend URL, Vertex 프로젝트/리전, 가능한 인증 계정 힌트 표시

### 2. 캔버스/레이어 편집 연결

- 좌측 도구에서 추가한 요소가 실제 미리보기 캔버스에 레이어로 들어가야 한다.
- 텍스트/이미지/도형 레이어는 위치, 크기, 투명도, 정렬, 깊이값을 조정할 수 있어야 한다.
- 작은 화면에서도 좌측 패널, 캔버스, 우측 설정이 잘리지 않고 스크롤로 접근 가능해야 한다.

### 3. 템플릿과 DB/온톨로지 연결

- 스펙/사이즈/색상/소재 템플릿은 DB 확정값을 우선 사용한다.
- DB에 값이 있으면 이미지 생성 프롬프트와 텍스트 레이어에 정확히 반영한다.
- DB 값이 없으면 추정값을 생성하지 않고 "확인 필요"로 표시한다.
- 온톨로지는 별칭, 제품군, 용도, 관련 옵션 연결에 사용한다.
- 어떤 DB 필드와 온톨로지 지식을 썼는지 로그에 자연어로 보여준다.

### 4. 검증 기준

- `app.html` inline script 문법 검사 통과
- 로컬 앱 `http://127.0.0.1:8081/app.html`에서 콘솔 오류 없음
- 작은 높이 화면에서도 모든 기능 버튼/입력창/패널이 우측 메인 스크롤로 접근 가능
- 생성된 섹션은 기존 15섹션 시스템과 충돌하지 않음
- Hookable ver2 기능은 옵션으로 켜고 끌 수 있음
