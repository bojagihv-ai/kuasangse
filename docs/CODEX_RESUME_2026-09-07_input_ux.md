## 바뀐 사용 순서

1. 입력·소스 메뉴 상단의 **새 제품명 → 제품 추가**.
2. 생성된 제품 카드에서 **Cafe24 분류 검색·선택, 상품정보, 기본사진·색상사진**을 입력한다. 선택한 분류 이름은 상품 종류에도 채워진다.
3. **작업큐에 N개 추가**를 누르면 제품명·이미지 모델·자동화 방식·판단 모델을 확인한다. 확인 버튼을 한 번 더 눌러야 전송한다.
4. 추가 성공 시 작업큐로 이동하며 새 작업을 표시한다. **작업큐 보기**로 직접 이동할 수도 있다.
5. 입력 원본은 지우지 않는다. 추가된 제품은 표시와 함께 잠기며, 실패한 제품은 남아 다시 시도할 수 있다.

CSV·공통값·파일명 묶기·색상명 일괄 도구는 아래 접힘 영역에 있다. 제품 카드의 개별 입력값이 CSV·공통값보다 우선한다. 복원 중과 큐 전송 중에는 입력을 잠가 오래된 스냅샷으로 덮어쓰는 경합을 막는다.
